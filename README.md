# dotfiles

Hyprland desktop (Quickshell bar and panels, matugen theming) on Ubuntu 24.04.

Target hardware: HP ENVY x360 15-ee0xxx (Ryzen 5 4500U, Radeon Vega 6).

Everything Hyprland-related is built from source into `~/.local`, because
Ubuntu 24.04 ships toolchains and libraries too old for current Hyprland.
GNOME stays installed as a fallback session.
